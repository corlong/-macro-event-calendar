# 宏观事件日历 · 重要信息源导航

一个**零依赖的单文件静态 HTML 页面**：所有数据内嵌在 JS 数组里，双击就能用浏览器打开，微信里也能直接打开。

汇总中国 CPI / PPI / PMI 的月度数据与统计局原文直达链接、宏观事件日历与三大指数公布日历、新闻联播入口，以及各机构官方发布入口。

## 文件说明

| 文件 | 用途 |
|---|---|
| `宏观事件日历_对外版.html` | **对外分享版**，给人看的主文件 |
| `重要信息源导航_内部维护版.html` | **内部维护版**，多数据来源徽章与维护弹层；数据数组必须与对外版保持同步 |
| `跨设备开发交接说明.md` | **换电脑或开新会话继续开发前，先读这个** |
| `重要信息源导航.html` | 早期版本，已被上面两个取代，保留作历史 |

## 怎么用

浏览器直接打开 `宏观事件日历_对外版.html` 即可，不需要装任何东西、不需要联网构建。

## 继续开发前必读

项目约定、数据源踩坑清单、明确不做的事项，全部写在 `跨设备开发交接说明.md` 里，改代码前先看一遍，能省掉大量重复踩坑。

## 技术形态

- 单个 HTML 文件，内联 CSS + JS，无外部依赖、无构建步骤
- 页面时间用 `TODAY` 变量运行时计算，不写死日期
- 日历默认定位当月，待公布条目过期自动翻成「已发布」
