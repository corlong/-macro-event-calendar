| 位置 | 原来 | 现在 |
|---|---|---|
| `TODAY` 常量 | 写死 `'2026-10-09'` | `new Date()` 算出来（`pad` 是函数声明会提升，可直接用） |
| 顶部 `.stamp` | 「更新：2026-10-09」写死 | `数据截至 <最新已发布数据日期> · 本页生成于 <今天> · 北京时间` |

| 日历默认月 | `renderCal('2026-10')` | 按当前月自动选中；跑出范围则落到最近一个月 |
| 3 条「待公布」 | 永远显示待公布 | 过了发布日自动改口「已发布」+ note 前缀「官方已于 X 发布，本页尚未补录」 |

### P1：移动端与分享
1. **表格横向滚动**：三张 `<table class="dtable">` 各包一层 `<div class="tbl-wrap">`（`overflow-x:auto`），窄屏加 `.tbl-wrap .dtable{min-width:600px}`。原来 5 列 + `white-space:nowrap` 在 375px 屏会被直接裁掉。
2. **弹层吸顶**：`modal-head` 本来就有 `position:sticky;top:0`，但**被父级 `.modal-box{overflow:hidden}` 废掉了**（overflow 非 visible 的祖先会成为 sticky 的包含块，而它不滚动 → sticky 无行程）。
   最终解法比「只删 overflow:hidden」更稳：改成 **`.modal-box{display:flex;flex-direction:column;max-height:calc(100vh - 98px)}` + `.modal-body{overflow:auto;flex:1 1 auto;min-height:0}`**，标题栏天然固定，不依赖 sticky 实现差异；并给 `.modal-head` 补 `flex:none`（否则默认 `flex-shrink:1` 会把标题栏压缩）+ `border-radius:16px 16px 0 0`（原来靠 overflow:hidden 裁圆角）。
   窄屏同步 `.modal-box{max-height:calc(100vh - 56px)}`。
3. **分享元信息**：补 `<meta name="description">`、`og:type/title/description`、`theme-color`。原来微信里贴链接抓不到摘要。
4. **favicon**：内联 SVG data URI（蓝底圆角方块 + 「宏」字）。注意 `#` 要写成 `%23`、「宏」要 UTF-8 百分号编码 `%E5%AE%8F`。

### 验证方法（本轮最有价值的沉淀）
1. **打桩 DOM 真跑渲染**（`_render.js`）：桩 `document.getElementById` 返回带 `innerHTML/dataset/classList` 的对象（同 id 返回同一实例），`calTabs.querySelectorAll` 特判返回 4 个带 `dataset.m` 的假标签，`window` 提供 `matchMedia/scrollY/scrollTo`，然后 `new Function('document','window','Date', js)`。
2. **时间旅行测试**（关键！静态页面必测）：把 `Date` 作为参数注入一个 `FakeDate`，无参构造时返回 `new RealDate(FAKE + 'T10:00:00')`，即可伪造「今天」。
   实测 `2026-10-11` → `2026-11-05`：公布日历「已公布」2 → 4 处、三张表「待公布徽章 1（过期 0）」→「1（过期 1）」、日历天数格 34 → 36（自动跳到 11 月）。**全部符合预期。**
3. **标签平衡检查的坑**：`/<th>/g` 匹配不到 `<th style="...">`，会误报不平衡。要用 `/<th\b[^>]*>/g`。内部版有 2 个带 style 的 th（在「链接怎么加进来」弹层里），所以对内部版必须用带属性的正则。
4. 补丁脚本一律：`rep()` 做**唯一命中断言**（`n!==1` 就 throw）、**写盘只在脚本末尾**（中途出错则不落盘，直接恢复备份重跑最安全）。

`agent-browser` 已装到托管 Node 工作区（**不在项目目录，会持久保留**）：

```bash
AB="C:/Users/Administrator/.workbuddy/binaries/node/workspace/node_modules/agent-browser/bin/agent-browser.js"
N="C:/Users/Administrator/.workbuddy/binaries/node/versions/22.22.2-6/node.exe"
"$N" "$AB" set viewport 1440 900
"$N" "$AB" open "<url>"

"$N" "$AB" screenshot "路径.png"
"$N" "$AB" close
```

**关键坑：守护进程会在多次 Bash 调用之间被回收**（下一次调用时 `snapshot` 直接 SIGTERM）。
→ **必须把 open / 交互 / screenshot / close 全部塞进同一条 Bash 命令**，用 `{ ...; }` 串起来，不能分次调用。
（另外 `close --all` 之后单独再 `open` 也会失败，同样是这个原因。）
