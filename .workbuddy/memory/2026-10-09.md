### 踩坑（重要，务必记住）
1. **`rep(old, new)` 里第一个模板是 old、第二个才是 new**。做 Edit 时误把 `rep(` + old 模板头改成 `const NEW_RENDER = ...`，导致新旧模板字符串首尾错位 → `SyntaxError: Unexpected template string`。
   **教训：改造长脚本时，不要用 Edit 去改「模板字符串的参数位置」，直接重写这一整段更安全。**
2. **替换函数必须做「唯一命中」断言**：`if (n !== 1) throw`。内部维护版里有多个片段与对外版同名（如 `reportType/dc_usa_cpi` 出现 2 次），只有**完整多行块**才唯一。
3. **内部维护版的 renderTable 段换行与对外版不同**（`function renderTable(kind, filter){  const ALL ...` 挤在同一行），精确 rep 会失败 → 改用**锚点裁剪整段替换**（`indexOf('/* ===== CPI / PPI 渲染')` 到 `indexOf('/* ===== 弹层控制')`），两版通吃。
4. 内部维护版文件的**写盘只在脚本末尾发生**，中途抛错则前面所有改动都不落盘 —— 所以「出错 → 恢复备份 → 修脚本 → 重跑」是安全流程。
